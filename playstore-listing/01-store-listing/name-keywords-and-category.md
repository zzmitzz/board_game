# Name, keywords & category

## App name options (30 characters max)

| Option | Chars | Why |
|---|---|---|
| **DeepTalk: Icebreaker Card Game** ⭐ recommended | 30 | Matches your privacy policy. Contains "icebreaker" and "card game", two strong search terms. |
| DeepTalk: Conversation Cards | 28 | Clear about what the app is; ranks for "conversation cards". |
| DeepTalk: Party Question Game | 29 | Leans toward the party and group crowd. |
| DeepTalk: Questions for Couples | 31 ❌ | One character too long. Use "DeepTalk: Couples Questions" (27) instead if you target couples. |

> If you change the name, also update the app name inside `resources/policy.html` so the two match.

The launcher label (`app_name` = **DeepTalk**) can stay short; it doesn't need to match the store title.

## Category

| Setting | Recommended value |
|---|---|
| App or game | **Game** |
| Category | **Card** (alternative: **Casual**) |
| Tags (pick up to 5 in Play Console) | Party · Multiplayer · Casual · Offline · Stylized |

*Why "Game › Card":* conversation-card apps are searched as card and party games. If you'd rather sit next to couples and self-care apps, choose **App › Entertainment**.

## Keywords to use naturally in the text (Google Play has no keyword field)

Main keywords: **conversation cards · icebreaker questions · couples questions · party game · deep questions · truth questions · date night · questions for friends · drinking game · get to know you**

Long-tail keywords: questions to ask your partner · questions for couples game · group icebreaker games · game night app · pass the phone game · 36 questions · would you rather alternative · deep conversation starters

Tips:
- Put the top 2–3 keywords in the **title** and **short description**, because those carry the most weight for search ranking.
- Use each keyword 2–4 times in the full description. Repeating a keyword more often than that is treated as keyword stuffing and can get the listing rejected.
- Don't name competitors (We're Not Really Strangers, Truth or Dare, and so on). That breaks Play's metadata policy.
